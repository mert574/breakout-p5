# Breakout

A browser brick-breaking game built with p5.js and p5.play. Move the paddle with
the mouse, bounce the ball and clear bricks to earn points.

[Play the game](https://mert574.github.io/breakout-p5/)

## Run locally

Open `index.html` in a browser. No installation or build step is needed.

Click to start, then move the mouse to control the paddle. Click again after
losing the ball to restart.
